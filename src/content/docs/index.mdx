diode is a non-modal editor for the terminal. It follows VS Code: the same keybindings, the same
`settings.json`, the same extension API. These pages cover what is specific to diode; for
everything that works the same way, they link to the VS Code documentation.

diode is in **alpha**: usable every day, while the extension API surface and the tools are still
growing. See the [roadmap](project/roadmap/).
